# Tanegashima runtime asset

The P2.4 Coastal Release retains the current coastal campus, paths and launch animation. The export replaces the 90 inventoried inherited M01 parts and 369 unresolved Polish gantry parts with project-authored launch infrastructure and command buildings. The audit found zero matches for those inherited objects and materials. The 14 animation clips and site metadata match the local P2.4 baseline. The Coastal Park pedestrian circuit and ceramic edges follow the exported terrain with a sampled minimum clearance of 4.5 cm.
